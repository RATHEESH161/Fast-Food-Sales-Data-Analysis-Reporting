# Fast-Food Sales Data Analysis & Reporting

## Overview
An end-to-end data analysis project in Microsoft Excel on fast-food sales data, covering data cleaning, descriptive statistics, pivot table analysis and reporting.

## Dataset
- 550 unique orders (after removing 6 duplicates)
- Columns: order_id, date, product, price, quantity, payment_method, manager, city
- Products: burgers, drinks, hot dogs, pizzas, sides & other

## Project Workflow
1. **Data Transformation**
   - Converted data to an Excel Table
   - Removed duplicate records
   - Cleaned text with TRIM and PROPER
   - Standardized date format
2. **Descriptive Statistics**
   - Created Revenue = Price x Quantity
   - Used Data Analysis ToolPak for summary statistics
   - Built a Box & Whisker chart
3. **Data Analysis (Pivot Tables)**
   - Bestselling products
   - Revenue trend over time
   - Revenue by city
4. **Reporting**
   - Manager-wise and product-wise revenue using SUMIFS
   - Grand totals
   - Conditional formatting

## Tools and Skills
Excel | Pivot Tables | SUMIFS | TRIM | PROPER | Data Analysis ToolPak | Charts | Conditional Formatting

## Key Insights
- Bestselling product: (sides and other)
- Top revenue city: (New York)
- Average revenue per order: (50000)
- Top performing manager: (Michael Johnson)
